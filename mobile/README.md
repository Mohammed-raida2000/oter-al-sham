# تطبيق الجوال (Flutter) — جمعية عطر الشام
واجهة عربية/إنجليزية، فاتح/داكن، تتصل بالخادم (`../backend`). **لم يُبنَ ولم يُشغَّل بعد**: بيئتي لا تستطيع تنزيل Flutter ولا Android SDK، فالكود لم يمر بالمُصرِّف. توقّع أخطاء بناء صغيرة في أول مرة.

## أسهل طريقة للحصول على APK (دون تثبيت Flutter): GitHub Actions
1. أنشئ حسابًا مجانيًا على github.com ومستودعًا جديدًا (Private).
2. ارفع **محتويات** هذا المجلد `mobile` إلى جذر المستودع، بما فيها `lib` و`assets` و`pubspec.yaml` والمجلد المخفي `.github`.
   إن لم يظهر `.github` عند الرفع: أنشئ ملفًا من الموقع باسم `.github/workflows/build-apk.yml` والصق محتوى الملف الموجود هنا.
3. افتح تبويب **Actions** ثم **Build APK** ثم **Run workflow**.
4. بعد 5–10 دقائق افتح التشغيل وحمّل **oter-alsham-apk** من Artifacts، وفيه `app-release.apk`.
5. انسخ الملف للجوال وثبّته (اسمح بالتثبيت من مصدر غير معروف).
إن فشل البناء: انسخ لي نص الخطأ من سجل Actions وأصلحه.

## تشغيل الخادم ليراه الجوال
الخادم (`../backend`) يجب أن يكون شغالًا والجوال يصل إليه:
- **عبر Cloudflare Tunnel (مناسب لك):** ثبّت `cloudflared` (`winget install Cloudflare.cloudflared`)، ثم شغّل الخادم `php artisan serve` وفي نافذة ثانية: `cloudflared tunnel --url http://localhost:8000`. سيطبع رابطًا `https://xxxx.trycloudflare.com`. الرابط مؤقت، ويعمل ما دام جهازك شغالًا.
- **أو عبر الشبكة المحلية:** `php artisan serve --host=0.0.0.0` وعنوان الخادم في التطبيق `http://192.168.x.x:8000` (الجوال والحاسوب على نفس الواي فاي). التطبيق يسمح بـ HTTP للتجربة فقط.
عند أول فتح للتطبيق اكتب عنوان الخادم، ثم اسم المستخدم وكلمة المرور (المسؤول الذي أنشأه `migrate --seed`).

## ما يحويه التطبيق
دخول، لوحة رئيسية بأرقام من الخادم، المخيمات (بحث، إضافة مع تنبيه التشابه، تفاصيل)، العائلات (بحث، فلاتر، تسجيل بأربع خطوات، ملف الأسرة، إرسال للمراجعة، اعتماد/إعادة)، المشاريع، التوزيعات (إنشاء، إضافة مستفيدين، تأكيد الاستلام بالهوية)، التقارير، إدارة المستخدمين وسجل التدقيق (للأدمن)، اللغة والمظهر. شاشة البداية 4 ثوانٍ عند أول تشغيل فقط، وتختلف الأزرار حسب صلاحيات الدور.

## غير موجود بعد
العمل دون إنترنت (لم يُعتمد)، تصدير CSV من الجوال، أيقونة التطبيق المخصصة، التوقيع للنشر على المتاجر، نسخة iOS (تتطلب جهاز Mac).
